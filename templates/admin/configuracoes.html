📅 Integração com Google / Apple Calendar

Copie o link abaixo e adicione como calendário por URL. Seus agendamentos aparecem automaticamente no Google Calendar E no app Calendário do iPhone/Mac.

📖 Como adicionar no Google Calendar / Apple (clique)
Google Calendar (computador): Vá em "Outros calendários" → "+" → "Por URL" → cole o link.
iPhone / Mac (Apple): Ajustes → Calendário → Contas → Adicionar Conta → Outro → "Adicionar Calendário Inscrito" → cole o link.
Android: Use o Google Calendar pelo computador para adicionar — depois sincroniza no celular.

📱 Notificações por WhatsApp

O sistema também gera botão "📱 Notificar cliente" em cada agendamento.
Deixe vazio para não enviar automaticamente. Use Evolution API, Z-API ou similar. Formato esperado: POST com {number, text}.
